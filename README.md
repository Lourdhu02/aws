# AWS ML Learning Repository

Structured AWS learning notes focused on machine learning infrastructure, MLOps, serverless patterns, data engineering, monitoring, GenAI, and project design.

## What is in this repo

- Topic notes in LaTeX under the numbered learning folders.
- Generated topic PDFs beside each `.tex` file, plus [AWS_ML_Study_Guide.pdf](AWS_ML_Study_Guide.pdf) at the repo root.s
- Certification support topics under [certifications](certifications).
- Asset generation scripts under [scripts](scripts).

## Learning path

| Phase | Scope |
|-------|-------|
| 00 | Foundations: IAM, EC2, S3, VPC |
| 01 | ML infrastructure: ECR, ECS, SageMaker, training, deployment |
| 02 | MLOps pipelines: CodePipeline, GitHub Actions, MLflow, SageMaker Pipelines |
| 03 | Serverless: API Gateway, Lambda |
| 04 | Data engineering: RDS, Glue, Athena, DynamoDB |
| 05 | Monitoring: CloudWatch, CloudTrail |
| 06 | GenAI: Bedrock, SageMaker JumpStart |
| 07 | Projects: batch inference, deployment pipeline, real-time CV, serverless ML API |
| 08 | Tooling: Docker, Terraform |
| 09 | Certifications: AWS ML Specialty, AWS Solutions Architect |


## Recommended use

1. Read one phase at a time from the topic notes or the master PDF.
2. Review the matching mind maps after each phase.
3. Do hands-on AWS labs for every topic before marking it complete.
4. Use [study-plan.md](study-plan.md) as the execution plan.
5. Track completion in [progress.md](progress.md).
