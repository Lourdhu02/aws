# GitHub profile README template

> This file is a TEMPLATE for your GitHub profile repo (the repo named `yourusername/yourusername`). It is NOT part of the aws repo itself. Copy it to your profile repo to get a stats-enhanced profile page.

---

If you want your GitHub profile to show off this study work, create a repo named `yourusername/yourusername` (must match your GitHub username) and put a `README.md` in it. That README renders on your profile page.

A profile README that pulls in stats typically includes:

- A short bio / what you're doing
- GitHub stats cards (contributions, repos, stars)
- A repo highlight card for this aws repo
- Optionally a "top languages" or "streak" card

Example structure (you'll need to fill in your username):

```markdown
# Hi, I'm <your name>

I'm studying AWS machine learning infrastructure end-to-end —
from IAM and VPC foundations through SageMaker, MLOps pipelines, serverless,
data engineering, monitoring, and GenAI.

Here's what I'm building along the way:

## Highlighted repo

[![Readme Card](https://github-readme-stats.vercel.app/api/pin?username=YOURNAME&repo=aws&theme=hook)]

## GitHub stats

[![GitHub stats](https://github-readme-stats.vercel.app/api?username=YOURNAME&show_icons=true&theme=hook)]

## Contribution graph

![GitHub contribution graph](https://github-readme-stats.vercel.app/api/contributions?username=YOURNAME&theme=hook)

## What I'm working on

- AWS ML Study Guide — a structured LaTeX + PDF learning path with labs and certification prep
- Hands-on AWS labs across IAM, EC2, S3, VPC, SageMaker, ECS, Lambda, Glue, Athena, CloudWatch, Bedrock, and more
```

Replace `YOURNAME` with your actual GitHub username.

The stats cards are provided by [github-readme-stats](https://github.com/anuraghazra/github-readme-stats). They're external images — they show live data from your GitHub account, including contribution activity, repo stars, and commit history.

To make the contribution graph green, keep committing to this repo as you work through the study plan.
