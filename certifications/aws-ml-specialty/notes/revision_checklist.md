# AWS ML Specialty Revision Checklist

Use this after finishing the main notes.

## Must be able to explain

- When to use SageMaker versus ECS versus Lambda for ML workloads
- How IAM, VPC, encryption, and logging protect ML systems
- How S3, Glue, and Athena fit into dataset preparation
- How training, evaluation, registration, and deployment connect
- When batch inference is better than real-time inference
- How monitoring differs for infrastructure health versus model behavior

## Must be able to do

- Design a secure training pipeline
- Design a low-latency inference path
- Choose a cost-aware AWS service combination for a given ML use case
- Explain rollback and observability for a production model release
- Identify why a proposed architecture is risky or overbuilt

## Weak areas to test yourself on

- data engineering patterns
- distributed training tradeoffs
- deployment modes
- networking boundaries
- access control design
- monitoring and auditability
