# AWS ML Specialty Scenario Questions

## Scenario 1

You need to retrain a fraud model weekly from S3 data, evaluate it automatically, and deploy only if validation metrics exceed a threshold. Which AWS services would you combine and why?

## Scenario 2

A computer vision model has strong accuracy in testing but poor latency in production. What architecture and observability checks would you inspect first?

## Scenario 3

A team is storing model artifacts in S3 but developers also have direct broad access to the bucket. What IAM and governance changes would you make?

## Scenario 4

You have bursty traffic and a lightweight model. Compare Lambda, ECS, and SageMaker serverless-style options for inference.

## Scenario 5

Your batch scoring workflow is expensive and slow in Athena and downstream jobs. What data layout and pipeline improvements would you investigate first?
