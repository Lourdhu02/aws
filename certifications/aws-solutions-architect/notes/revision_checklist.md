# AWS Solutions Architect Revision Checklist

## Core architecture checks

- Can you explain the difference between object, block, relational, and key-value storage?
- Can you choose between EC2, containers, and serverless under latency, scale, and control constraints?
- Can you design a VPC with public and private layers correctly?
- Can you explain high availability, scaling, and failure isolation in plain terms?
- Can you secure workloads with IAM, network controls, and encryption?

## AWS ML-specific architecture crossover

- Can you place a model endpoint in the wider application architecture correctly?
- Can you explain how data flows from ingestion to storage to analytics to ML?
- Can you identify cost risks in overbuilt compute and storage designs?
- Can you describe how monitoring, audit, and rollback work together?

## Final check

If you can compare options clearly and justify tradeoffs under a business constraint, you are studying at the right depth.
